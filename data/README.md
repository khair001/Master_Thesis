# Experimental Dataset

The raw ADC datasets used in this thesis are not included in this GitHub repository due to their large file sizes.

The experimental data were collected using TI IWR6843 mmWave radar evaluation boards and a DCA1000 data capture card. The measurement campaign includes interference-free baseline recordings and recordings with an active interfering radar across indoor and outdoor environments.

Detailed information about the measurement scenarios, radar configurations, and dataset organisation is provided in the main repository README and the accompanying Master's thesis.
